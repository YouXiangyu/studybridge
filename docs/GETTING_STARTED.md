# 初始化与使用教程

[下载最新版本](https://github.com/YouXiangyu/studybridge/releases/latest) · [产品介绍](https://github.com/YouXiangyu/studybridge) · [问题反馈](https://github.com/YouXiangyu/studybridge/issues)

## 1. 放好程序与工作区

先确认电脑已安装 [Node.js 22 或更新版本](https://nodejs.org/en/download)，并且 `node --version` 能在新终端中运行。需要 AI 问答时，使用单独安装的 [Codex CLI](https://developers.openai.com/codex/cli/)；可先在新终端运行 `codex --version` 检查。尚未安装时通常可运行 `npm install -g @openai/codex`，然后用自己的账号完成登录。已经装好时不用重复安装；笔记桥不会自动选择 Codex 桌面应用内部的 CLI。

下载 Windows 11 x64 发布版 `StudyBridge.exe`，放到有写权限的长期目录后双击。启动器检查 Node 版本、释放阅读器资源并打开默认浏览器；以后复用已校验缓存。EXE 不内置 Node、Codex 或浏览器，不需要 Python。

首次运行会显示工作区选择窗口，可以新建工作区，或打开已有笔记桥工作区。请选择自己的长期保存位置，避免临时下载目录；取消选择不会创建默认工作区。以后会记住已成功打开的位置。系统托盘中出现笔记桥图标后，可右键选择“打开工作区”找到数据。

文档导入检查与渲染需要已安装的 Microsoft Edge；PPTX 转换仅使用已安装的 Microsoft PowerPoint。转换前请保存并关闭已有 PowerPoint 窗口和进程；检测到 PowerPoint 已运行时，应用会拒绝转换，避免接管用户文档。旧 `.ppt` 请自行导出 PDF。

本文说明 v0.4.0 的安装与使用。应用、系统托盘与浏览器使用统一图标，下载时请核对版本和校验值。

如果浏览器没有打开，从托盘选择“打开笔记桥”。启动日志在工作区 `run/`。应用本身不需要管理员权限。缺少 Node 时启动器会提示安装；缺少 Codex 只影响 AI 功能。

## 2. 导入第一份课件

1. 在资料库点击“添加课件”；阅读器中也可从文件菜单导入。
2. 填写项目名称，可选填课程名称。
3. 选择原课件 PDF 或 PPTX。中文译文 PDF/PPTX 可选，之后阅读时按原页组织。
4. 点击“开始学习”，任务窗口显示检查、转换和导入进度。首次项目没有内置课程或个人样稿。

文件会复制到工作区，PPTX 经本机 PowerPoint 转为 PDF；原文件移动后不影响阅读。只导入原文无需连接 AI。原文和译文成对导入时会尝试 AI 页码匹配；之后也可在“管理课件”补充 PDF/PPTX 译文，或生成中文译稿。已有 PDF 不直接替换，以免笔记和圈画错位；更换文档时请新建项目。

已有 `.study.json` 时，选择“导入 .study.json”；它会建立新副本，避免覆盖已有项目。

资料库支持搜索、新建课程文件夹和重命名。点击卡片进入阅读器，点击“管理课件”可调整名称、课程、所在文件夹，并查看 PDF 与笔记的实际存储位置。阅读器返回资料库时会先保存，保存失败会停留在当前页面。

在“工作区设置”中可以改名，或把笔记改存到工作区内的相对目录（如 `notes`）。应用先复制并核验笔记，再切换保存位置，旧文件保留；目标存在不同内容时会拒绝调整。`data` 表示默认项目目录。笔记目录不支持工作区外的任意路径。

“切换工作区”和“新建工作区”会打开原生目录选择框；选择完成后等待所有标签保存，再进入目标资料库。开发服务固定使用启动目录，目录选择由 EXE 提供。

### 递归扫描与批量导入

1. 点击资料库“AI 扫描 / 任务”。默认范围是工作区上级目录（包含子文件夹），也可改为当前工作区；先核对界面显示的实际路径。
2. 选择模型与思考强度，点击“AI 扫描课件”。应用检查 PDF/PPTX，并依据相对路径与代表页文字区分课件、译稿、参考教材、作业和不确定文件，再提出中英配对。
3. 核对每组原文、译文、名称与课程。较高和中等可信度课件默认勾选，低可信度、不确定和重复项需自行检查。展开全部文件可查看读取失败项及原因。
4. 点击“导入勾选课件”。按内容摘要识别重复项；原文件在扫描后变化时会拒绝使用旧结果。成对课件尝试自动页码匹配，低可信度或无法匹配的原页留空，并显示警告。
5. 可关闭任务窗口继续阅读，稍后从同一入口查看进度。取消只停止尚未完成的工作，已成功导入的项目保留；失败项显示各自原因。

任务进行时，请先完成或取消任务再切换工作区或正常退出。扫描结果尚未导入时可关闭窗口；再次打开后仍应核对文件和配对。

### 生成缺少的中文译文

在“管理课件”中选择“AI 生成中文译文”，或在批量清单勾选“为缺少中文译文的课件调用课件翻译技能”。应用内置技能正文、制作参考和已接受示例三份资源，生成与原页对应的中文教学译稿；任务可取消。

每个原页及对应译文续页都进行结构校验、渲染检查和视觉审核，每页最多 3 轮制作/审核（含修复重试）。任一原页最终未通过，本次译稿不会挂接到学习项目，可在任务中查看失败原因。制作清单和审核记录保存在工作区的任务数据中。

需要替换文字的译文页通常以原页位图为底，叠加可选取的中文文字层；这类译文页不保留原矢量元素，制作清单会记录栅格化情况。原文 PDF 保留。扫描件、复杂版面或文字位置不可靠的课件可能拒绝生成；自动审核通过后仍须人工核对，不能视为内容正确性的保证。已完成单页合成材料的真实模型试译，不能据此推断真实课程或复杂版面的翻译质量；具体范围见验收记录。

## 3. 调整英文与中文页对应

在目录中选择一张英文原页，打开文件菜单中的“调整译文对应”，填写它对应的中文 PDF **实际页码**。例如英文第 2 页对应中文第 3、4 页，就把 3 和 4 关联到英文第 2 页。

PDF 实际页码从第一页开始计数，与页面印刷的章节编号可能不同。同一英文原页的中文续页会共享笔记和问答。没有译文对应的原页会明确显示暂无对应译文。

资料库“管理课件 → 查看和修正”可一次核对整份课件。点击“AI 建议”会提取两份 PDF 各页文字摘要，发送给本机 Codex 所连接的模型；候选带可信度和说明，可逐行改动。勾选已检查并点击“应用对应关系”后才保存。文件或对应关系在此期间变化时，旧候选会失效，请重新生成。

手动“AI 建议”支持每份 PDF 最多 300 页、每页最多 2500 字符摘要、总计最多 50 万字符，超限会拒绝生成候选。批量导入的自动匹配遇到这些输入限制或没有可用文字时，会保留文档导入、将对应关系留空并显示警告，可随后手动设置。不含 OCR；AI 对齐不会改变原页笔记、圈画或问答归属。

## 4. 阅读与记笔记

- 左侧目录或 `←` / `→` 切换英文原页；阅读区依次显示原页及对应译页。
- `↑` / `↓` 循环滚动定位当前原页关联的译文续页，不改变笔记和问答所属原页。在输入框、编辑器、输入法组词期间或弹窗内，不接管这些翻页键。
- 用画笔或高亮标注。橡皮擦删除命中的整条笔迹或高亮，撤销可恢复本次擦除。
- 标注会关联当前笔记并插入可点击的正文链接；点击链接可回到课件中的位置。
- 右侧上方写分页笔记，可添加图片、数学公式和代码块，点击星标将笔记列为重点。
- 自动保存状态显示在笔记区域。若提示保存失败，保留页面并点击重试；不要在未保存时关闭程序。

快捷键：`Ctrl+S` 保存，`Ctrl+Shift+S` 导出学习包，`Ctrl+F` 查找。全文搜索需要 PDF 自带文字层；扫描图片型课件暂不支持 OCR 搜索。

## v0.4.0 导入与页码修复

- **已有译文却没有对应页**：打开课件详情，点击“修复页码关联”。程序检查译文里的原页和续页标记，只补空关联；已有非空对应保持不变，冲突会列在候选中。核对原文与中文的物理页号后应用。
- **大文件**：本地扫描支持最大 512 MiB 的 PDF/PPTX。超过浏览器单文件 65 MB 上限时，把文件放在扫描范围内，再用“AI 扫描 / 任务”导入。
- **并发与暂停**：批量导入默认 1 个并发，可选 2 或 3。暂停停止领取新课件，等已开始的课件完成保存后显示“已暂停”。此时可保存退出，之后从任务中继续；完成的项目不会重做。继续时可调整并发数。扫描、单独生成译文和补充译文任务仍使用取消操作。
- **查看原因**：展开任务的匹配详情，查看具体原页、中文候选页、空文字、低可信度或标记冲突等原因。
- **缓存**：工作区设置显示缓存占用与可释放空间。清理保留暂停、待恢复任务所需文件和轻量审核记录；已清理扫描的结果需重新扫描后才能再次导入。

## 5. 初始化 AI 问答

1. 点击连接状态，打开连接设置，点击“刷新模型”查询本机 CLI 的账号状态和模型目录。
2. 若已登录 ChatGPT，可直接使用；未登录时点击“使用 ChatGPT 登录”，通过官方链接在浏览器完成授权，再回到笔记桥点击“刷新模型”。
3. 从当前 CLI 返回的目录中选择模型和思考强度。聊天、扫描、配对、页码匹配与翻译共用设置，默认 `gpt-6.1-sol` / `medium`，按工作区记住选择。不同 CLI 版本或账号可能提供不同目录；目录中没有所选模型或不支持所选强度时，必须由你另选，不静默替换。

模型设置区域也提供“刷新模型”和“重启 AI 连接”。刷新会重新获取模型目录，不使用先前的目录缓存；重启会关闭并重建笔记桥自己启动的 Codex 连接，不关闭其他 Codex 应用，不清除课件、笔记、问答记录或模型设置。问答正在准备或生成、课件任务尚未结束时会拒绝重启，请先等待完成或取消。重启连接不会重新安装 CLI；若修改了 Windows 环境变量，可能仍需保存退出后重新打开笔记桥。

连接失败时先查看界面显示的具体错误。账号查询与模型目录查询会分别诊断，不会因账号查询失败就误判为没有模型。网络、登录和 CLI 发现是不同环节，不能仅凭模型列表为空判断代理或 VPN 是否有问题。

笔记桥默认从 PATH 和 npm 安装位置发现独立 Codex CLI，排除桌面应用内部 CLI；也支持通过 `CODEX_CLI_PATH` 明确指定 `codex.exe` 或 `bin/codex.js`。应用使用其已有登录状态，不创建第二份登录目录，也不复制账号凭据。浏览器里已登录 ChatGPT 不代表 CLI 已登录，请以连接检测结果为准。不要复制他人的 Codex 登录目录。

选中课件、笔记或回答的文字，右键选择“加入 AI 提问”，也可直接输入问题。**加入输入框不会发送；点击发送或按 `Enter` 才上传上下文。** `Shift+Enter` 换行；输入法组词、选词期间按 Enter 不发送。 发送内容包括问题、当前适用课件单页截图、当前笔记分页截图，以及手动添加的附件。问答需要网络和账号可用额度。

AI 扫描会发送候选文件相对路径与抽样文字；配对也依据这些摘要。本地页码修复不发送课件给 AI；混合页码匹配仅发送尚未通过可靠标记确定的可用文字摘要；生成译稿及视觉审核逐页发送原稿与译稿图片和文字。只有主动启动相应 AI 操作才发送，通过当前所选模型处理。

生成中可以停止，已生成部分按页保存。普通回答保持独立，点击“加入笔记”才写入笔记。对选中的代码块使用“AI 修改”时，原内容若已被编辑或删除，结果会保留为候选，避免覆盖新的修改。

## 6. 保存、退出与备份

选择文件菜单或系统托盘里的“保存并退出”。多个笔记桥标签页会分别完成保存；全部成功后，本地服务和它启动的 Codex 进程退出。某个页面保存失败时应用保持运行，返回该页面重试。

只关闭浏览器标签会保留托盘服务。后台冻结的标签不会被超时跳过，请切回页面让它完成保存。如果页面已经崩溃且无法恢复，可在托盘选择“强制退出…”并确认；强制退出、强制关机或任务管理器终止都可能丢失尚未保存的内容，日常应使用正常退出。

备份有两种方式：

1. **单个项目**：点击“另存为”导出 `.study.json`，包含 PDF、对应关系、笔记、圈画、附件和问答。
2. **全部项目**：正常退出后，复制工作区 `workspace.json`、`data/` 和设置过的笔记目录到备份位置；也可以复制整个工作区，`runtime/` 只是可重建缓存。恢复时先退出应用，保留原数据副本再恢复，避免覆盖错误目录。

分享前检查学习包内容。不要分享自己的 Codex 登录目录、运行日志或含个人内容的截图。

## 7. 更新版本

1. 导出或备份重要数据。
2. 使用“保存并退出”，确认原实例结束。
3. 用新版本替换旧 `StudyBridge.exe`，再次双击。

应用会继续使用记住的工作区，按新版本内容建立自己的运行缓存。不要删除 `workspace.json`、`data/` 或设置过的笔记目录。本版没有自动更新功能。

旧版工作区可直接打开，缺少 `workspace.json` 时会建立资料库配置，原项目不会搬动。打开开发目录前请先保存并停止开发服务；不能同时用 EXE 和开发服务写同一个数据目录。也可导出 `.study.json` 后导入新工作区，导入创建副本，AI 会话编号会重置，但文字记录仍保留。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| Windows 提示未知发布者 | 首版尚未代码签名。核对下载来源及 Release 的 SHA-256，再决定是否运行。 |
| 再次双击没有新窗口 | 同一工作区只允许一个后台实例；程序会尝试重新打开已有页面。 |
| 提示找不到 Node | 安装 Node.js 22+，确认 `node --version` 可用，关闭旧启动器后重新双击。修改 PATH 后可能需要重新打开文件管理器或重新登录 Windows。 |
| 端口 4318 被占用 | EXE 默认自动选择端口，不需要手动处理。不要把旧地址当作固定入口。 |
| PPTX 转换失败 | 确认已安装 Microsoft PowerPoint，保存并关闭正在运行的 PowerPoint 后重试；旧 `.ppt` 请手动导出 PDF。 |
| 文档检查无法启动 | 确认已安装 Microsoft Edge；后台文档处理使用单独的 Edge 实例。 |
| 自动页码对应留空 | 先尝试课件详情的本地页码修复，再查看逐页原因。没有可靠标记或正文时需人工核对；剩余 AI 候选受 300 页、50 万字符限制。 |
| 翻译审核未通过 | 查看失败原页与任务说明，检查源文件文字和版面；本次失败译稿不会自动挂接到项目。 |
| 问答无法连接 | 查看具体连接错误，确认单独安装的 Codex CLI 可用，再尝试“刷新模型”或“重启 AI 连接”；已安装无需重装，课件和笔记仍可本地使用。 |
| 默认模型不在列表中 | 模型目录由当前 CLI 返回；手动选择目录中的模型和支持的思考强度，应用不会静默替换 `gpt-6.1-sol`。 |
| 重启 AI 连接被拒绝 | 等待正在准备或生成的问答、课件任务完成，或取消并等待收尾后重试；无需删除笔记或重置设置。 |
| 保存退出一直等待 | 切回其他笔记桥标签页，等待后台页面恢复运行，处理保存错误后重试。 |
| 需要定位工作区 | 右键系统托盘图标，选择“打开工作区”。 |
| 移动工作区后打不开 | 退出后检查 `%LOCALAPPDATA%/Kejian/workspace.txt` 中的路径，或使用 `StudyBridge.exe --workspace "绝对路径"` 指定位置。该参数只对本次启动生效。 |
