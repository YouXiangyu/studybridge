# 初始化与使用教程

[下载最新版本](https://github.com/YouXiangyu/studybridge/releases/latest) · [产品介绍](https://github.com/YouXiangyu/studybridge) · [问题反馈](https://github.com/YouXiangyu/studybridge/issues)

## 1. 放好程序与工作区

先确认电脑已安装 [Node.js 22 或更新版本](https://nodejs.org/en/download)，并且 `node --version` 能在新终端中运行。需要 AI 问答时，还需安装 [Codex CLI](https://developers.openai.com/codex/cli/)；通常可运行 `npm install -g @openai/codex`，然后用自己的账号完成登录。已经装好时不用重复安装。

下载 Windows 11 x64 发布版 `笔记桥.exe`，放到有写权限的长期目录后双击。启动器检查 Node 版本、释放阅读器资源并打开默认浏览器；以后复用已校验缓存。EXE 不内置 Node、Codex 或浏览器，不需要 Python。

首次运行会显示工作区选择窗口，可以新建工作区，或打开已有笔记桥工作区。请选择自己的长期保存位置，避免临时下载目录；取消选择不会创建默认工作区。以后会记住已成功打开的位置。系统托盘中出现笔记桥图标后，可右键选择“打开工作区”找到数据。

如果浏览器没有打开，从托盘选择“打开笔记桥”。启动日志在工作区 `run/`。应用本身不需要管理员权限。缺少 Node 时启动器会提示安装；缺少 Codex 只影响 AI 功能。

## 2. 导入第一份课件

1. 在资料库点击“添加课件”；阅读器中也可从文件菜单导入。
2. 填写项目名称，可选填课程名称。
3. 选择英文原课件 PDF。中文译文 PDF 为可选，之后阅读时按原页组织。
4. 点击“开始学习”。首次项目没有内置课程或个人样稿。

请先将 PPT/PPTX 导出为 PDF。当前不直接读取 PowerPoint 文件，也不自动生成译文。文件会复制到工作区；原文件移动后不影响阅读。可以只导入英文原文，之后在“管理课件”中补充中文 PDF。已有 PDF 不直接替换，以免旧笔记和圈画错位；更换文档时请新建项目。

已有 `.study.json` 时，选择“导入 .study.json”；它会建立新副本，避免覆盖已有项目。

资料库支持搜索、新建课程文件夹和重命名。点击卡片进入阅读器，点击“管理课件”可调整名称、课程、所在文件夹，并查看 PDF 与笔记的实际存储位置。阅读器返回资料库时会先保存，保存失败会停留在当前页面。

在“工作区设置”中可以改名，或把笔记改存到工作区内的相对目录（如 `notes`）。应用先复制并核验笔记，再切换保存位置，旧文件保留；目标存在不同内容时会拒绝调整。`data` 表示默认项目目录。笔记目录不支持工作区外的任意路径。

“切换工作区”和“新建工作区”会打开原生目录选择框；选择完成后等待所有标签保存，再进入目标资料库。开发服务固定使用启动目录，目录选择由 EXE 提供。

## 3. 调整英文与中文页对应

在目录中选择一张英文原页，打开文件菜单中的“调整译文对应”，填写它对应的中文 PDF **实际页码**。例如英文第 2 页对应中文第 3、4 页，就把 3 和 4 关联到英文第 2 页。

PDF 实际页码从第一页开始计数，与页面印刷的章节编号可能不同。同一英文原页的中文续页会共享笔记和问答。没有译文对应的原页会明确显示暂无对应译文。

资料库“管理课件 → 查看和修正”可一次核对整份课件。点击“AI 建议”会提取两份 PDF 各页文字摘要，发送给本机 Codex 所连接的模型；候选带可信度和说明，可逐行改动。勾选已检查并点击“应用对应关系”后才保存。文件或对应关系在此期间变化时，旧候选会失效，请重新生成。

AI 对齐支持每份 PDF 最多 300 页、每页最多 2500 字符摘要、总计最多 50 万字符。不含 OCR；没有可提取文字的扫描件请手工对应。AI 建议不会修改原页笔记、圈画或问答归属。

## 4. 阅读与记笔记

- 左侧目录切换英文原页；阅读区依次显示原页及对应译页。
- 用画笔或高亮标注。橡皮擦删除命中的整条笔迹或高亮，撤销可恢复本次擦除。
- 标注会关联当前笔记并插入可点击的正文链接；点击链接可回到课件中的位置。
- 右侧上方写分页笔记，可添加图片、数学公式和代码块，点击星标将笔记列为重点。
- 自动保存状态显示在笔记区域。若提示保存失败，保留页面并点击重试；不要在未保存时关闭程序。

快捷键：`Ctrl+S` 保存，`Ctrl+Shift+S` 导出学习包，`Ctrl+F` 查找。全文搜索需要 PDF 自带文字层；扫描图片型课件暂不支持 OCR 搜索。

## 5. 初始化 AI 问答

1. 点击连接状态，打开“Codex 连接设置”。
2. 获取官方登录链接，在浏览器完成自己的 ChatGPT 登录授权。
3. 回到笔记桥检测连接，选择账号实际提供的模型和思考强度。

笔记桥使用本机 Codex CLI 及其登录状态，不创建第二份登录目录，也不复制账号凭据。浏览器里已登录 ChatGPT 不代表 CLI 已登录，请以连接检测结果为准。不要复制他人的 Codex 登录目录。

选中课件、笔记或回答的文字，右键选择“加入 AI 提问”，也可直接输入问题。**加入输入框不会发送；点击发送才上传上下文。** 发送内容包括问题、当前适用课件单页截图、当前笔记分页截图，以及手动添加的附件。问答需要网络和账号可用额度。

生成中可以停止，已生成部分按页保存。普通回答保持独立，点击“加入笔记”才写入笔记。对选中的代码块使用“AI 修改”时，原内容若已被编辑或删除，结果会保留为候选，避免覆盖新的修改。

## 6. 保存、退出与备份

选择文件菜单或系统托盘里的“保存并退出”。多个笔记桥标签页会分别完成保存；全部成功后，本地服务和它启动的 Codex 进程退出。某个页面保存失败时应用保持运行，返回该页面重试。

只关闭浏览器标签会保留托盘服务。后台冻结的标签不会被超时跳过，请切回页面让它完成保存。如果页面已经崩溃且无法恢复，可在托盘选择“强制退出…”并确认；强制退出、强制关机或任务管理器终止都可能丢失尚未保存的内容，日常应使用正常退出。

备份有两种方式：

1. **单个项目**：点击“另存为”导出 `.study.json`，包含 PDF、对应关系、笔记、圈画、附件和问答。
2. **全部项目**：正常退出后，复制工作区 `workspace.json`、`data/` 和设置过的笔记目录到备份位置；也可以复制整个工作区，`runtime/` 只是可重建缓存。恢复时先退出应用，保留原数据副本再恢复，避免覆盖错误目录。

分享前检查学习包内容。不要分享自己的 Codex 登录目录、运行日志或含个人内容的截图。

## 7. 更新版本

1. 导出或备份重要数据。
2. 使用“保存并退出”，确认原实例结束。
3. 用新版本替换旧 `笔记桥.exe`，再次双击。

应用会继续使用记住的工作区，按新版本内容建立自己的运行缓存。不要删除 `workspace.json`、`data/` 或设置过的笔记目录。本版没有自动更新功能。

旧版工作区可直接打开，缺少 `workspace.json` 时会建立资料库配置，原项目不会搬动。打开开发目录前请先保存并停止开发服务；不能同时用 EXE 和开发服务写同一个数据目录。也可导出 `.study.json` 后导入新工作区，导入创建副本，AI 会话编号会重置，但文字记录仍保留。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| Windows 提示未知发布者 | 首版尚未代码签名。核对下载来源及 Release 的 SHA-256，再决定是否运行。 |
| 再次双击没有新窗口 | 同一工作区只允许一个后台实例；程序会尝试重新打开已有页面。 |
| 提示找不到 Node | 安装 Node.js 22+，确认 `node --version` 可用，关闭旧启动器后重新双击。修改 PATH 后可能需要重新打开文件管理器或重新登录 Windows。 |
| 端口 4318 被占用 | EXE 默认自动选择端口，不需要手动处理。不要把旧地址当作固定入口。 |
| 问答无法连接 | 确认本机 Codex CLI 可用，再在设置中检测登录和网络；课件和笔记仍可本地使用。 |
| 保存退出一直等待 | 切回其他笔记桥标签页，等待后台页面恢复运行，处理保存错误后重试。 |
| 需要定位工作区 | 右键系统托盘图标，选择“打开工作区”。 |
| 移动工作区后打不开 | 退出后检查 `%LOCALAPPDATA%/Kejian/workspace.txt` 中的路径，或使用 `笔记桥.exe --workspace "绝对路径"` 指定位置。该参数只对本次启动生效。 |
