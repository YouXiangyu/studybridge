## v0.3.0 主功能验证

- 完整自动化回归 **205 项通过，0 失败、0 取消、0 跳过**，使用真实 Edge 浏览器及本机 PowerPoint，两个测试文件并发。
- ↑/↓ 在同一英文原页对应的多张译文间定位；←/→ 切换英文原页。输入框、中文输入法选词和打开的对话框不会误触阅读快捷键。
- 聊天 Enter 发送、Shift+Enter 换行；模型与思考强度在问答、扫描、页码匹配、翻译与审核之间共享，默认精确为 `gpt-6.1-sol / medium`。
- 工作区上级或当前目录递归扫描，保留课程译稿目录，排除程序数据和临时结果；人工复核配对后批量导入。文件指纹去重、扫描后变动、越界和目录链接均有测试。
- 批量任务提供逐项结果、警告和取消；启动保存、取消、收尾清理及最终写盘均纳入退出屏障。重启不会把未完成任务误标为完成。
- PPTX 包括隐藏页转换为 PDF，转换前后原稿指纹一致；不接管已打开的 PowerPoint 会话。
- 一页原文关联多页译文；生成译稿使用原页标签、PDF 页面标签和显式对应表。关联前检查原稿/映射版本，不覆盖已有译稿、笔记和圈画。
- 原页尺寸、图形与公式像素、旋转文字保护、深色背景对比度、中文与保留文字的可提取性，以及数学符号精确 Unicode 均通过合成 PDF 测试。
- 内置翻译技能正文与两份参考文件和用户指定原件逐字一致。每页最多三轮制作与审核，失败或取消的结果不会作为完整译稿关联。
- 桌面与窄屏批量复核界面已视觉检查；资料库、笔记、圈画、代码块、导入导出及旧阅读深链完成回归。

一次全量运行中出现过 Windows `EPERM` 原子重命名保存错误，原测试在状态文件写入后过早读回，未等待整次保存。已补强测试，要求保存响应全部成功、资料库切换完成且无 API 错误；连续五次针对性运行通过。操作系统此次拒绝重命名的精确原因未复现，没有加入未经验证的生产重试补丁。保存失败仍由现有界面保留编辑并提示重试。

## 真实模型验证

通过本机 Codex 读取到 `gpt-6.1-sol`，支持中等思考强度。使用该模型和强度，对一页自造的“Gradient descent”英文课件进行了真实翻译，不使用个人课程材料。

最终试跑生成一页中文 PDF，页码对应为原第 1 页 → 译第 1 页。模型指出一次简注换行问题，自动修订后视觉审核通过；应用从最终 PDF 实际提取并核对中文译文、下划线术语、原公式与原页标签，全部匹配。最终渲染已人工视觉查看。生成 PDF 的 SHA-256 为 `5d03e30e245ad112caaca32e8bce3a53070bc06594b8417583e327015eccb882`。

较早的一次试跑发现简注前缀重复、图片审核不适合证明文本层可复制，以及单一字体缺少数学符号，均在本次交付前修正。现在程序提供实际文本提取证据，模型检查可见内容与版面；数学字形按原 Unicode 使用本机补充字体。

这一结果只验证单页样本的实际连通与处理流程，不代表已经审核任意课程或整套复杂课件。用户课程未被自动批量翻译。

最终 EXE 的 **9/9 Windows 集成场景通过**：缺少或过旧 Node、中文/空格路径、重复启动、保存后退出、端口冲突、移动/替换 EXE、终止受控启动器或 Node 后清理各自子进程。测试使用受控 CLI，不更改个人认证状态。记录中的遗留测试进程数为 0。

此前已对 v0.3.0 EXE 完成新增功能验收：在隔离工作区通过真实 HTTP 接口上传合成 PPTX，自动转换并导入 **2/2 页（含一张隐藏页）**；核对原稿指纹、内置三份技能文件、PDF 字体及文档模块，随后正常退出启动器和 Node。该测试也未留下后台实例。

发布包不包含 Node、Codex CLI、Edge、PowerPoint 或系统字体。Node 22+ 为基础运行要求；PDF 文档处理使用 Edge；PPTX 转换需要已安装的 PowerPoint；AI 使用用户本机 Codex 登录；译稿使用本机中文 TrueType 字体及可用的数学符号补充字体。无需 Python。

## 已知边界

- 仅在当前 Windows 11 x64 环境验证，尚未在洁净虚拟机、其他 Windows 版本或 ARM64 上验收，EXE 尚未签名。
- 替换文字的译页通常使用 144 DPI 原页图像底层，并叠加可选取文字；此类底层不保留原始矢量。任务结果与制作清单会注明。
- 扫描件、文字无法可靠定位、非均匀背景或复杂混排可能无法完成翻译；最终检查失败时不关联半成品。
- AI 页码对齐沿用每份 PDF 最多 300 页、摘要合计 50 万字符的范围。超出或没有文字层时，批量导入仍保留文件，显示警告并留下空映射供手工设置。
- PowerPoint 已运行时不会自动接管，请自行保存并关闭后再转换。
- 原生工作区 A → B 切换的完整人工验收仍未完成；既有控制协议、路径预检与跨标签保存屏障有自动化覆盖。
- 本地文件写入、模型输出与图片审核均可能失败；任务会保留明确结果，不将失败视为完成。正常退出等待保存，强制退出或断电仍可能丢失未提交的编辑。
